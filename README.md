## 今回の修正
Gemini版に残っていた `?` 表示を追加修正しました。

- 「? 前の問題」→「◀ 前の問題」
- 「次の問題 ?」→「次の問題 ▶」
- 「? 前へ」→「◀ 前へ」
- 「? 採点する」→「✅ 採点する」
- 模擬試験の選択状態 `?` → `✓`
- 結果画面の「正解 ?」→「正解 ✓」
- 結果画面の「不正解 ?」→「不正解 ✗」
- 問題26の `h1?h6` → `h1〜h6`

アイコンはHTML数値文字参照で記述し、文字コード変換による再発を抑えています。
